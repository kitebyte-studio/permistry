Paper and Spigot plugin.yml errors

"Invalid plugin.yml" caused by "mapping values are not allowed here"

Server log
[DirectoryProviderSource] Error loading plugin: Invalid plugin.yml
org.bukkit.plugin.InvalidDescriptionException: Invalid plugin.yml
	at io.papermc.paper.plugin.provider.type.spigot.SpigotPluginProviderFactory.create(...)
Caused by: mapping values are not allowed here
 in 'reader', line 5, column 32:
    description: Shop plugin. Usage: /shop open
                                   ^

What it means

The server could not read your plugin.yml at all, so the plugin is skipped and does not appear in /plugins. The rest of the server starts as usual.

The log points at the exact line and puts a ^ under the spot where reading stopped. That spot is almost always a colon in the middle of a value.

What causes it

In YAML, a colon followed by a space means "a key ends here and its value starts". So in

description: Shop plugin. Usage: /shop open

the server sees description: and then a second Usage: on the same line, which is not allowed. It happens most often in description, usage and permission descriptions, because they are normal sentences. A colon without a space after it, like in https://example.com or 12:30, is fine.

How to fix it

Put the whole value in quotes:

description: "Shop plugin. Usage: /shop open"

If the text itself contains double quotes, use single quotes around it instead, or write \" inside double quotes. Rebuild the jar and restart the server.
