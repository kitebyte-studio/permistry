Paper and Spigot plugin.yml errors

"commands are of wrong type"

Server log
org.bukkit.plugin.InvalidDescriptionException: commands are of wrong type

What it means

The commands section, or one command inside it, is not laid out as a section, so the server refuses the plugin.

What causes it

Usually a command written on one line, like commands: home, or a command whose description is put right after its name.

How to fix it

Before

commands:
  home: Teleports you home

After

commands:
  home:
    description: Teleports you home
