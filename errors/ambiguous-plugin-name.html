Paper and Spigot plugin.yml errors

"Ambiguous plugin name ... for files ... and ... in 'plugins'"

Server log
[ModernPluginLoadingStrategy] Ambiguous plugin name 'MyPlugin' for files 'plugins\MyPlugin-2.0.jar' and 'plugins\MyPlugin-1.0.jar' in 'plugins'

What it means

Two different jar files in your plugins folder both declare the same name in their plugin.yml. The server cannot run two plugins with the same name, so it picks one of the two jars and silently skips the other. The server keeps starting; there is no crash.

What causes it

Usually an old copy of the same plugin was never deleted when a new version was dropped in, for example MyPlugin-1.0.jar sitting next to MyPlugin-2.0.jar. It also happens with two unrelated plugins that happen to pick the same name.

How to fix it

Look in your plugins folder for more than one jar that could contain the plugin named in the message, and remove the one you do not want. Which jar the server actually keeps is not guaranteed, so do not rely on it picking the newer one — check the version with /plugins or /version MyPlugin after removing the duplicate and restarting.
