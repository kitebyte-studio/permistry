Paper and Spigot plugin.yml errors

"... does not contain a paper-plugin.yml or plugin.yml! Could not determine plugin type, cannot load a plugin from it!"

Server log
[DirectoryProviderSource] Error loading plugin: java.lang.IllegalArgumentException: Directory 'plugins\MyFile.jar' does not contain a paper-plugin.yml or plugin.yml! Could not determine plugin type, cannot load a plugin from it!

What it means

The server opened this jar looking for a plugin and found neither a plugin.yml nor a paper-plugin.yml inside it. Without one of these files the server has no way to know the plugin's name, version or main class, so it refuses to load the jar at all. Everything else on the server keeps running.

What causes it

The most common cause is a jar that is not a server plugin: a client-side mod, a plain library, a Maven/Gradle dependency, or a build output copied into plugins by mistake. It can also happen with a real plugin whose plugin.yml ended up in a sub-folder inside the jar instead of at the top level, which is the same mistake "The jar has no plugin.yml" on this checker reports from your build output.

How to fix it

Open the jar with any zip tool and look at the top level. If there is no plugin.yml or paper-plugin.yml there, the jar is not a Paper/Spigot plugin and does not belong in the plugins folder — remove it. If you built the jar yourself, make sure plugin.yml sits directly in src/main/resources (not in a sub-folder) so it ends up at the jar's root.

Check the whole file. Paste your plugin.yml or drop the plugin jar into Permistry. It finds this and about 40 other problems, and explains each one in plain words. It runs in your browser and nothing is uploaded.
