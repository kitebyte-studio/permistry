Paper and Spigot plugin.yml errors

"depend is of wrong type" (also softdepend, loadbefore, authors)

Server log
org.bukkit.plugin.InvalidDescriptionException: depend is of wrong type

What it means

The server expects a list here but found a single piece of text, so it refuses the plugin. The same message appears for softdepend, loadbefore and libraries, and as "authors are of wrong type" or "contributors are of wrong type".

What causes it

The value is written as plain text instead of a list.

How to fix it

Before

depend: Vault
authors: Alice

After

depend: [Vault]
authors: [Alice]

A list can also be written one entry per line, each starting with - . For a single author you can use author: Alice (singular) instead.
