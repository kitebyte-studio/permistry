Paper and Spigot plugin.yml errors

"UnsupportedClassVersionError ... compiled by a more recent version of the Java Runtime"

Server log
[ModernPluginLoadingStrategy] Could not load plugin 'MyPlugin.jar' in folder 'plugins'
org.bukkit.plugin.InvalidPluginException: java.lang.UnsupportedClassVersionError: com/example/MyPlugin has been compiled by a more recent version of the Java Runtime (class file version 70.0), this version of the Java Runtime only recognizes class file versions up to 69.0

What it means

The plugin was built for a newer version of Java than the one your server runs on. Java refuses to read the plugin's code, so that one plugin is skipped. The server itself keeps starting and the other plugins load normally.

What causes it

The two numbers in the message are Java versions in disguise: 65 is Java 21, 66 is Java 22, and so on, one more per release (69 is Java 25, 70 is Java 26). If the first number is higher than the second, the plugin author compiled with a newer Java than your server uses.

How to fix it

You have two options. Either update the Java that runs your server to the version the plugin needs (the first number in the message), or download an older release of the plugin that was built for your Java version. If you are the plugin author, compile with a lower release level, for example options.release = 21 in Gradle, so the jar runs on servers that have not upgraded yet.
