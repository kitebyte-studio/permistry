Paper and Spigot plugin.yml errors

"Unknown/missing dependency plugins"

Server log
org.bukkit.plugin.UnknownDependencyException: Unknown/missing dependency plugins: [Vault]. Please download and install these plugins to run 'MyPlugin'.

What it means

The plugin lists another plugin under depend, and that plugin is not on the server, so it will not load.

What causes it

The required plugin is missing, or the name in depend does not match the other plugin's name exactly (case matters).

How to fix it

Before

depend: [vault]

After

depend: [Vault]

If the plugin can work without the other one, move it to softdepend and check at runtime whether it is installed.
