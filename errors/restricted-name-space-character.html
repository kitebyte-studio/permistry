Paper and Spigot plugin.yml errors

"Restricted name, cannot use 0x20 (space character) in a plugin name"

Server log
org.bukkit.plugin.InvalidDescriptionException: Restricted name, cannot use 0x20 (space character) in a plugin name.

What it means

Paper does not allow spaces in plugin names and refuses to load the plugin. Older Spigot versions quietly replaced spaces with underscores, so a plugin that worked years ago can fail now.

What causes it

The name in plugin.yml contains a space.

How to fix it

Before

name: My Plugin

After

name: MyPlugin

Other plugins find yours by this name in their depend lists, so tell them if you change it.
