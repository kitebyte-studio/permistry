Paper and Spigot plugin.yml errors

"Bad artifact coordinates ..., expected format is <groupId>:<artifactId>:<version>"

Server log
Caused by: java.lang.IllegalArgumentException: Bad artifact coordinates gson, expected format is <groupId>:<artifactId>[:<extension>[:<classifier>]]:<version>

What it means

The server downloads the libraries listed in libraries before loading the plugin. One entry is not a full Maven coordinate, so the plugin fails to load.

What causes it

An entry in libraries is missing the group, artifact or version part.

How to fix it

Before

libraries:
  - gson

After

libraries:
  - com.google.code.gson:gson:2.11.0

Copy the coordinate from Maven Central. The format is group:artifact:version.
