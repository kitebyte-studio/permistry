What you get

GitHub Action

Each problem shows up on the exact line of plugin.yml in your pull request, with a summary table on the run page. The step fails when something would crash the server, stop the plugin from loading or drop a command or permission.

Command line tool

Checks plugin.yml, paper-plugin.yml and built jars from the terminal. Point it at your project folder and it finds the files itself. Text or JSON output and exit codes for scripts.

Build and git setup

A ready Gradle task that runs after jar, workflows for Gradle and Maven, and a pre-commit hook. Copy one folder and add one step.

Details

  • Checks the plugin.yml inside the built jar too: main class present, Java version it was compiled for, ${version} placeholders the build forgot to replace.
  • Needs Node.js 18 or newer, which GitHub runners already have. Nothing else to install.
  • Runs offline. Your files never leave your machine or your CI.
  • Same rules as the web checker, each one tested on a real Paper 26.3 server. See the errors it explains.
